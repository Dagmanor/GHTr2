# Role Assignment & Handoff Checklist

Purpose: Ensure that role ownership and handoffs are explicit at project kickoff, during major milestones, and before releases.

Checklist
- [ ] Confirm core assignments at kickoff
  - Project Manager: overall schedule, communications owner
  - Product Manager: product vision, success metrics owner
  - Engineering Manager: staffing & capacity owner
  - Technical Lead: architecture & quality owner
  - QA Lead: test strategy owner
  - Release Manager: release coordination owner
  - SRE/Platform: production operability owner
  - UX Researcher: user validation owner
  - Data/Analytics: metrics instrumentation owner
- [ ] Document role responsibilities in project README or project charter (link to docs/octoacme-roles-and-personas.md)
- [ ] For each cross-team dependency, identify owner (name + role) and expected delivery date
- [ ] For each major deliverable, record acceptance criteria and the role responsible for sign-off
- [ ] Before release: confirm release owner, rollback plan, monitoring dashboards, and on-call contacts
- [ ] Post-release: assign owner for metrics review and action items

Usage
- Add this checklist as an artifact on the project board or link it to the release milestone.
